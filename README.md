STPVD Projects

Verilog design exercises from the Summer Training Program on VLSI Design (STPVD) at IIIT Allahabad, June-July 2026. The program was co-sponsored by the IEEE Circuits and Systems Society, UP Chapter, and covered digital and analog IC design flows.

Highlight

booth_multiplier/: a parameterized (default 8-bit) signed radix-2 Booth multiplier, split into a datapath and a 7-state FSM controller, with a self-checking testbench. Start here.
